scale → Zoom，rotate → Spin

预期 PPTX：左侧 Zoom（0.6s，对象中心）；右侧 Spin 180°（0.9s，强调类，角度 = 首末帧旋转差）

scale(0) → scale(1)
@keyframes cssZoom {
  from { transform: scale(0); }
  to   { transform: scale(1); }
}
PPTX：Zoom · 0.6s（进入类，对象中心）
trigger: after（默认）
rotate(-180°) → 0°
@keyframes cssSpin {
  from { transform: rotate(-180deg); }
  to   { transform: rotate(0deg); }
}
PPTX：Spin 180° · 0.9s（强调类，顺时针）
trigger: after（默认）
验收要点：Zoom 为进入动画（元素先隐藏再放大出现）；Spin 为强调动画（元素可见，原地旋转 180°）；旋转角度取首末帧 rotate 差值并保留方向符号。
