CSS @keyframes 自动推断08 / 19

opacity: 0 → 1 推断为 Fade

预期 PPTX：2 个 Fade 淡入（各 0.7s）；第二个带 0.3s 延迟；CSS 捕获的动画默认 afterPrevious，按 DOM 顺序自动连播

CSS 淡入
@keyframes cssFade {
  from { opacity: 0; }
  to   { opacity: 1; }
}
animation: cssFade 0.7s both;
PPTX：Fade · 0.7s（无需任何 data 属性）
trigger: after（默认）
CSS 淡入 · 带延迟
animation: cssFade 0.7s ease-out 0.3s both;
（animation-delay: 0.3s）
PPTX：Fade · 0.7s，延迟 0.3s
trigger: after（默认）
验收要点：进入放映后两个 Fade 依 DOM 顺序自动连播（先左后右，右侧延迟 0.3s）；动画窗格中效果名 Fade、计时「上一动画之后」；缓动曲线被丢弃（PPTX 线性），属预期行为。
