组合场景 · 来源优先级14 / 19

同一元素：声明式优先于 CSS 捕获

两个元素带同一段 CSS 飞入动画；左卡额外声明了 data-animation —— 预期 PPTX：左卡只有 Zoom（声明式胜出），右卡 Fade + Fly In（CSS 推断，对照组）

CSS fly + 声明 zoom
CSS: animation: cssFlyFromL 0.8s both;
+ data-animation="zoom-in"
PPTX：仅 Zoom · 0.6s（click）
CSS 捕获被声明式覆盖
trigger: click（声明式）
仅 CSS fly（对照）
CSS: animation: cssFlyFromL 0.8s both;
（无 data-animation）
PPTX：Fade + Fly In · From Left 并行
CSS 推断结果
trigger: after（默认）
验收要点：左卡在动画窗格中只有一条 Zoom（click 触发、0.6s），不应出现 Fly/Fade；右卡为 Fade+Fly 并行（after、0.8s）。验证「显式声明 wins over 环境动画」的覆盖规则。
